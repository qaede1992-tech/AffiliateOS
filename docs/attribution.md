# Conversion attribution

AffiliateOS now has an explicit, one-to-one attribution boundary between a legacy conversion and a tracking link.

A conversion can be attributed once to an active tracking link. Campaign analytics then derive attributed conversions, revenue, commission, and conversion rate from that explicit relationship.

The attribution record does not rewrite the legacy conversion's offer reference. This keeps the existing conversion/commission domain intact while giving analytics a canonical campaign path.

Attribution is intentionally explicit: AffiliateOS does not infer a conversion's campaign from unrelated offer IDs or from timing alone.
